# 拯救派大星 🎈⭐🗑️

一个网页小游戏：控制**降落伞**接住从天空掉落的**派大星、星星和垃圾袋**，把派大星和垃圾袋送回
左下角的**救助站**得分；别让派大星掉出屏幕，也别把星星带回来。

纯静态页面（HTML + CSS + ES Module JS，无构建步骤、无外部图片/音频素材，全部程序化绘制与 WebAudio 合成音效）。

## 玩法

| 规则 | 数值 |
| --- | --- |
| 送回 1 个 **派大星** | **+5 分** |
| 送回 1 个 **垃圾袋** | **+1 分** |
| 送回 1 颗 **星星** | **−7 分**（可为负） |
| 1 个派大星掉出屏幕下方 | **生命 −1** |
| 生命初始 / 扣光 | **5 颗** / 游戏结束 |
| 降落伞一次可携带 | **1 个**（送回救助站后才能再接） |

- **点击 / 按住拖动**屏幕移动降落伞（也支持方向键 / WASD 微调）
- **右上角暂停按钮**（或 `Esc` / `P`）可冻结游戏进程，暂停界面点「继续游戏」恢复
- 携带物品时移动会略微变慢；掉率约 派大星 40% / 垃圾袋 34% / 星星 26%，越久掉落越快

## 本地运行

ES Module 需要 HTTP 访问，不能直接双击 `index.html`：

```powershell
cd <本目录>
python -m http.server 8794
# 浏览器打开 http://127.0.0.1:8794/
```

## 部署（GitHub Pages）

本仓库已按 GitHub Pages 静态托管准备好（含 `.nojekyll`，相对路径引用）：

1. 推送到 GitHub 仓库的 `main` 分支；
2. 仓库 **Settings → Pages → Build and deployment → Source: Deploy from a branch**；
3. 选择 **main / (root)** 保存，稍等 1 分钟；
4. 访问 `https://<你的用户名>.github.io/<仓库名>/`。

## 目录结构

```
index.html      页面结构（开始界面 / 游戏画面 / 结算界面）
style.css       界面样式
js/engine.js    游戏逻辑（掉落、接取、上缴计分、生命与难度）
js/art.js       Canvas 绘制（派大星/星星/垃圾袋/降落伞/海底背景/救助站/HUD）
js/main.js      主循环（输入、特效、合成音效、界面流程）
.nojekyll       关闭 GitHub Pages 的 Jekyll 处理
```
