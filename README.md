# 拯救派大星 🎈⭐🗑️

一个用「降落伞」接住从天空掉落物的网页小游戏：把**派大星**和**垃圾袋**送回左下角的**救助站**得分，
别让派大星掉出屏幕，也别把**星星**带回来。

## 运行

需要静态服务器（ES Module 不能用 `file://` 直接打开）：

```powershell
cd "D:\godot_engine\New\拯救派大星"
python -m http.server 8794
# 浏览器打开 http://127.0.0.1:8794/
```

也可以部署到任意静态服务器（Nginx / GitHub Pages 等），无需构建步骤。

## 玩法规则

| 规则 | 数值 |
| --- | --- |
| 送回 1 个 **派大星** | **+5 分** |
| 送回 1 个 **垃圾袋** | **+1 分** |
| 送回 1 颗 **星星** | **−7 分** |
| 1 个派大星掉出屏幕下方 | **生命 −1** |
| 生命初始 / 扣光 | **5 颗** / 游戏结束 |
| 降落伞一次可携带 | **1 个**（送回救助站后才能再接） |

- 天空会随机掉落三种物品：派大星、星星、垃圾袋（掉率约 40% / 26% / 34%，时间越久掉落越快、星星越多）。
- 降落伞会自动飞向**玩家点击的位置**；按住拖动可持续引导（也支持方向键 / WASD）。
- 接住的物品挂在降落伞下方：**一次只能接 1 个**，带着物品飞回左下角**救助站**结算得分后，才能接下一个。
- 带着物品时降落伞会略微变慢，需要规划「接取 → 送回」的路线。
- 星星是干扰项：带回救助站会扣 7 分（分数可以为负）。
- 派大星掉到屏幕下方扣 1 颗生命，扣光 5 颗游戏结束，结算显示得分、救回数量与漏接数量。

## 文件结构

```
拯救派大星/
├── index.html            页面结构（开始界面 / 结算界面）
├── style.css             界面样式（卡片、按钮、遮罩）
├── js/
│   ├── engine.js         游戏逻辑：掉落物、降落伞、接取、上缴计分、生命与难度（纯逻辑，可单测）
│   ├── art.js            Canvas 绘制：派大星、星星、垃圾袋、降落伞、海底背景、救助站、HUD
│   └── main.js           主循环：输入、特效、合成音效、界面流程
├── tests/
│   ├── engine.test.mjs   逻辑单元测试（37 项）
│   └── page.test.mjs     页面层冒烟测试：DOM/Canvas 桩件下执行 main.js（27 项）
├── package.json
└── README.md
```

## 自测

```powershell
cd "D:\godot_engine\New\拯救派大星"
node tests/engine.test.mjs   # 逻辑：计分 / 接取 / 扣命 / 结束 / 难度 / 掉率
node tests/page.test.mjs     # 页面：加载、点击移动、结算界面、重开、长时间运行稳定性
```

全部为程序化绘制与 WebAudio 合成音效，**无任何图片/音频外部资源**，拷贝目录即可运行。
